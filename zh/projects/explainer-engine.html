Explainer Engine

把代码和技术概念，讲得更直观。

我想尝试用动画把代码中的关系和技术概念讲清楚，也想探索 AI 能怎样帮助完成这个过程。Explainer Engine 是其中的一次尝试：从讲解脚本出发，生成带旁白和字幕的视频，并在渲染前检查脚本中的源码引用。

从脚本到画面

输入是一份 YAML {% include glossary-term.html term="storyboard" %}，写明镜头、旁白和源码引用，不是上传任意代码就能自动得到可靠讲解。下面节选第二段视频中 per-line 镜头的真实脚本，右图取自现有视频的第 12 秒。

这段脚本规定画面上的代码、引用的文件行和必须找到的证据；同一镜头的曲线写为 2 * x。画面代码是标注为 simplified 的简化视图，不冒充逐字源码。查看完整脚本。

  1. 检查引用引用校验门检查引用行中是否包含脚本声明的证据。
  2. 按固定规则生成场景脚本编译成 {% include glossary-term.html term="manim" %} 场景代码，渲染阶段没有模型参与。
  3. 渲染与配音由 Manim 渲染画面，配上合成旁白；这里的样例同时提供中英字幕轨。

可选的 explainer plan 可以借助 AI 从指定源码范围起草脚本。它是前面的准备步骤，草稿仍需通过同一道引用校验门；模型不在渲染阶段临时生成画面。

能核对哪些证据

第二段视频的脚本与源码位于公开 commit c345e66。按仓库说明准备环境并检出该 commit 后，可运行：

explainer verify examples/evidence-budget.story.yaml

这条命令只检查引用，不会重新渲染视频。它不证明讲解语义正确，也不证明教学效果。

  • 视频使用的 storyboard
  • 证据常量：第 55–58 行
  • 预算计算：第 205–211 行
  • 拒绝弱引用：第 312–313 行

这里的预算是每行两个 token 的位置，下限五个、上限二十四个；少于两个 token，或没有强 token 的引用会被丢弃。这段视频从 c345e66 渲染的出处由本站说明，画面本身不能证明这一点：脚本引用所在仓库，没有固定 commit，因此徽标只写 verified，不带 commit。

较早样例与本地快照的边界

第一段 Harness-Field 视频来自更早的 diagram-canvas 本地快照，是引擎实际输出。五种力来自研究知识库；画面上的 simplified 标签与 verified @ commit 徽标，标出简化视图以及「memory force」所引用的源码行和 commit。当时在渲染前通过了引用校验门，但历史校验结果缺少公开运行证据，无法由外部独立核验。视频能展示产物与这些标记，不能替代那份运行证据。

项目摘要保留的是 local tag explainer-plan：这个较晚的本地快照加入了可选脚本起草步骤，未改变校验后生成画面的流程。仓库现已公开，但这个 tag 没有公开发布，因此外部无法核对这份精确快照。公开的 c345e66 示例比它更新，不能把两者当成同一份证据。

取舍与约束

动画可以让关系更直观，也可能让一个错误说法显得更可信。这里的校验只能约束引用，不能代替对讲解本身的判断。

引用对不上，就停止渲染。引用校验门检查声明的证据是否出现在源码中；若脚本固定了 commit，还会检查仓库 HEAD 是否匹配，并拒绝未显式允许的脏工作区。 代价：写脚本时需要维护可解析的引用，源码变动后可能要重新调整。

简化视图保留出处标记。simplified 与 verified 徽标呈现的是校验门的结论，不是讲解正确性的保证。 代价：画面要留空间给标签和引用，实际可用于图与代码的区域更小。

模型起草，固定规则生成代码。相同脚本通过确定性代码生成得到相同场景代码；实际视频仍受渲染环境、字体和旁白资源影响。 代价：新的镜头类型需要修改引擎，不能只靠改提示词；规划器也不能绕过校验门。

与桌面工具共用渲染核心。同一套与 Qt 无关的核心也供批量渲染 GUI 使用。 代价：核心改动需兼顾两个使用方，不能为了脚本运行方便而阻塞 GUI。

实现记录：「共用代码」和「共用一个包」，是两个决定

使用边界

  • 不是上传任意代码就能生成可靠讲解的工具；输入仍是一份明确的脚本。
  • 不是渲染时由 LLM 即兴生成视频；AI 规划器只负责可选的脚本起草。
  • 图示画布能把关系做成动画，但视频是否有助于学习，还没有验证。
  • 画面代码是有引用的简化视图，不是逐字源码查看器。
  • 引用校验不证明讲解语义正确。徽标给出校验结论，需要核对具体说法时仍应看源码链接与证据。
  • 较早视频的历史校验结果无法独立核验；源码公开不等于所有本地快照都已发布。
