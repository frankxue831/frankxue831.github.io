Frank Xue — 软件工程师

借助 AI，做有用的软件。

我喜欢借助 AI 编程助手做软件，也很享受这个过程。我通常从自己遇到的问题出发，写清楚想做什么，再借助 AI 实现。我想继续探索，看看这样还能做出什么有价值的东西。

这里收录了我的一些项目，大多用 Rust 编写：gm-crypto-rs 是实现国密 SM2、SM3、SM4 算法的密码学库，已在 crates.io 发布；面向 AI 编程 Agent 和 CI runner 的工具目前是私有项目；讲解视频生成流程则用 Python 编写，源码已公开，处于预发布阶段。

案例

gm-crypto-rs 是一个纯 Rust 的国密 SM2 / SM3 / SM4 密码学库，已在 crates.io 发布。在使用国密工具的过程中，我发现 Rust 生态中的相关工具还比较少，于是开始了这个项目。案例页介绍了要解决的问题、工作的分工、验证依据，以及这些依据不能支持哪些结论。这个库没有经过独立审计。
