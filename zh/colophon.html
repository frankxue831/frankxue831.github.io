本站说明

这个站是怎么搭的。

做出来是为了好读，也为了能核对。没有构建魔法，不向外发一个请求，整套源码都摆在外面。

构建

一个用 Jekyll 生成、托管在 GitHub Pages 上的静态站点—— 没有 JavaScript 框架，不做客户端渲染，除了 Jekyll 本身再没有别的构建步骤。组成很精简：github-pages gem，外加 jekyll-feed、jekyll-seo-tag 和 jekyll-sitemap；一份手写、基于一套设计变量（design tokens）的样式表；以及分散在 7 个职责集中的文件里、合计约 580 行的原生 JavaScript。这些 JavaScript 全是渐进增强——把它关掉，每个页面照样能用。

字体

页面大标题、首页的章节标题和笔记里的小标题、站标里的斜体 f，以及段落、列表和笔记这些正文，用 EB Garamond；导航、站名、元数据、小号技术标签和项目页的章节标题用 IBM Plex Mono；列表里的项目和笔记标题、本页这类页面的章节标题、按钮、标签等界面文字用你系统里的无衬线体，不下载网络字体。拉丁字体都自托管在本站——不走字体 CDN，不向 Google Fonts 发请求。

中文字形由你自己的系统提供。本站不下载任何中文字体，所以具体显示哪一款，取决于你的设备装了什么。中文页面和英文页面的分工一样：页面大标题、笔记里的小标题和正文用衬线体（样式表里排第一的是 Noto Serif SC，没有的话就用系统自带的中文衬线体），界面文字用无衬线体，标签用等宽字体。

如何核对

「这里不追踪你」不是一句空话，而是被强制执行的。一条严格的 Content-Security-Policy 把 script-src 钉死在本站（外加两段内联的主题与动效脚本，按哈希放行），并设了 connect-src 'self'——页面无法向别处发起请求：没有站点分析（analytics）、没有 CDN、没有远程调用。

每一处改动都由构建后校验器（scripts/validate_site.rb）把关， CI 在每个 pull request 和推送到 main 时都会跑它：核对元数据、双语 hreflang、安全策略和静态资源完整性。源码公开：可读、可 clone、可开 issue。

隐私

没有站点分析（analytics），没有 cookie，没有第三方资源——没有追踪。主题选择以 frankxue.theme 保存在浏览器本地；本站不会传输它，清除站点数据即可移除。也没有联系表单、不收集邮箱；找我的方式是在 GitHub 上开公开的 issue 或 discussion，让对话留在代码旁边。
