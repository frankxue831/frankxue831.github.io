About me.

I'm Fengxiang (Frank) Xue, a software engineer with a background in mathematics and computer science. I like building software with AI and enjoy turning ideas into things I can use. I want to keep exploring what else I can create with AI that is useful.

I was happy when gmcrypto-core v1.16.0 was published on crates.io. Seeing someone star a project on GitHub or submit a PR motivates me too. This kind of feedback is one reason I want to keep going.

While working with Chinese cryptographic tools, I found relatively few related tools in the Rust ecosystem, which led me to start gm-crypto-rs. I set out the requirements, used AI coding assistants to implement them, and focused on practical usability and compatibility with existing implementations such as GmSSL.

I'm still learning Rust and exploring how to use AI more effectively. This site records some of my attempts: what I have made, where each project stands, and what still needs work.
