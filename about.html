(02) About

About, more or less.

A working draft. I'd rather say a little honestly than a lot vaguely.

I'm Frank — a software engineer who works mostly in Rust, mostly at the seam between developer tools and the systems they sit on top of.

Lately that's meant four things: a pure-Rust SDK for the Chinese national crypto standards with constant-time-designed secret-handling paths guarded by an in-CI leak harness; a repository memory layer for AI coding agents that exposes a typed, decaying memory graph over MCP; a small observability CLI that exists because debugging self-hosted GitHub Actions runners on macOS shouldn't take an hour; and a rendering pipeline for concept videos that refuses to draw an explanatory claim it can't verify against the source.

I build tools where correctness, state, and failure modes need to remain inspectable. The projects differ in subject; the recurring concern is the same — software that can explain what it knows, what it changed, and where its boundaries are.

In practice that is a preference for the unglamorous parts of the work: clear naming, the regression gate that catches a leak before a release, the comment that finally explains why. The opinionated stuff.

The project pages here are the honest snapshot — each states its release state, evidence, and limits, including for the work that isn't public. GitHub carries the source for what is.
