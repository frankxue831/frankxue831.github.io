(02) About

About, more or less.

A working draft. I'd rather say a little honestly than a lot vaguely.

I'm Fengxiang (Frank) Xue, a software engineer with a background in mathematics and computer science. I like using AI to build software that's useful, and I'm exploring how people can understand, guide and evaluate what it helps create.

In practice I start from a gap I have run into, write down what the software needs to do, and use AI coding assistants to implement it. I pay most attention to whether the result is practical to use, and to keeping the problem, the decisions and the evidence written down with their limits. gm-crypto-rs is the fullest example: there I also cared about compatibility with existing implementations such as GmSSL, reviewed changes myself at first, and then shifted more of the code review to AI agents following defined rules. It has not been independently audited, and its timing tests are statistical evidence on the tested paths and hardware, not a proof. Verification and cryptography appear often on this site because of that project, not because they are the whole of what I do.

The projects themselves are on the Work page: the cryptography library, a repository-context tool for AI coding agents, a small diagnostic CLI for self-hosted CI runners, and a pipeline that renders concept videos whose on-screen claims are checked against their source. They are mostly written in Rust, with Python where it fits.

Across these projects, I prefer the unglamorous parts of the work: clear naming, the timing check that flags a leak on the pull request that introduces it, the comment that finally explains why. The opinionated stuff.

The project pages here are the honest snapshot — each states its release state, evidence, and limits, including for the work that isn't public. GitHub carries the source for what is public.
